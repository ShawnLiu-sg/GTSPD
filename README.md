# GTSPD Benchmark Instances for Energy-Aware Truck–Drone Routing

C++17 truck-drone routing and comparison solvers, experiment scripts, synthetic and converted route inputs, and flight-power calibration data. Build instructions are in work/solver and work/compare.

Flight-power source: https://doi.org/10.1016/j.eswa.2024.124172

Public route source: https://github.com/schasarah/FSTSP-MD-Experiment-Results
