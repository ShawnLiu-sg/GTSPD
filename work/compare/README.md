# 卡车与无人机联合配送对比实验

本 C++17 程序运行论文第 6.4 节的算法对照和消融。各方法使用同一算例、配对种子、相同求解时限和共同的可行性与成本评价器。每次计时从构造初始解开始。同一算例与种子下的方法串行运行，运行顺序按算例与种子的组合轮换。

## 运行示例

在解压目录的 PowerShell 中运行 Windows x64 可执行文件。

```powershell
.\truck_drone_compare.exe benchmark-example.txt demo-results
```

样例包含两个合成算例、两个配对种子、七种方法，共 28 次运行。两个达标阈值用于演示已达标和右删失。正式实验应在测试前固定目标值、种子、算法参数、算例和检查点。

## 对照方法

| 标识 | 方法 |
|---|---|
| `hybrid` | 完整 ALNS，包含同站和跨站的精确重分配 |
| `plain` | 关闭精确邻域，保留相同的 ALNS 算子和搜索设置 |
| `fixed_q` | 用清单给定的固定移除规模替代 Sigmoid 调度 |
| `nonadaptive` | 移除、修复和噪声选择使用恒定权重 |
| `within_stop` | 保留相同的精确邻域调用方式，每个包裹的发射站固定为调用前所在的站点 |
| `order_first` | 基于客户序列的独立分割基线。逐块枚举可行架次并精确求解集合划分，再用最短路径选取连续分块 |
| `vns` | 六邻域可变邻域搜索，包含卡车 2-opt、双向模式迁移、跨站交换、架次迁站和架次内重排 |

## 配置清单

实例沿用主求解器的 `STDRP 1` 输入。每个实例给出订单、飞行和卡车参数，以及坐标或道路和飞行距离矩阵。清单的时间预算和种子用于所有被选方法，实例内的 `SEARCH` 迭代上限和 `ANNEAL` 最低温度仍控制 ALNS 的提前结束。研究对比可在调参阶段选择足够大的迭代上限，并记录各方法的实际停止时间。

| 字段 | 值的含义 |
|---|---|
| `BENCHMARK` | 格式版本 `1` |
| `BUDGET_MS` | 每次求解的共同墙钟上限，单位 ms |
| `CHECKPOINTS` | 数量和递增的时间点。程序自动补上最终时限 |
| `SEEDS` | 数量和种子列表 |
| `METHODS` | 数量和上表的方法标识列表 |
| `FIXED_Q` | 固定移除规模，由训练算例选定 |
| `ORDER_FIRST` | 最大连续分块长度（1–16）、每次客户序列扰动的 2-opt 步数 |
| `VNS` | 每次扰动的可行移动数 |
| `BOOTSTRAP` | Bootstrap 重采样次数及其独立随机种子 |
| `CASES` | 数量，随后每行是 `算例ID 分层ID "实例路径" 预设目标值`。实例路径相对于清单，可使用 `/`。目标字段填 `-` 可关闭达标计时 |
| `END` | 清单结束 |

## 数据输出

| 文件 | 内容 |
|---|---|
| `runs.csv` | 每次运行的时限内最佳可行路线、目标及分项、架次、精确邻域调用次数、目标达成状态和时间。架次字段形如 `5:8 7\|5:6`，表示从节点 5 同站起降的两个架次 |
| `checkpoints.csv` | 每个时间点之前已获得的最佳可行目标值，可绘制收敛曲线 |
| `table7.csv` | 每个算例与方法的跨种子平均目标值、达标和删失次数，以及截断到共同上限的平均达标时间 |
| `summary.csv` | 各分层、方法和检查点的平均目标值、独立算例间标准差及有效运行数。先在同一算例内对种子取平均，再对算例等权汇总 |
| `paired.csv` | 各方法相对 `hybrid` 的配对目标差及 95% Bootstrap 区间。先在同一算例内对匹配种子取平均，再按分层重采样独立算例。差值为方法目标减完整方法目标 |

目标未达成时，按统一预算记录右删失。`table7.csv` 的截断平均时间对未达标运行使用共同上限，须与达标数一起解读。区间使用至少两个有效配对算例计算。若检查点前尚无可行解，目标值留空，状态为 `no_incumbent`。

## 从源码构建

在 Visual Studio x64 Native Tools Command Prompt 中运行。

```cmd
cl /nologo /std:c++17 /EHsc /O2 /MT /Fe:truck_drone_compare.exe compare.cpp io.cpp search.cpp model.cpp exact.cpp order_first.cpp vns.cpp
```

也可通过同目录的 `CMakeLists.txt` 构建 C++17 命令行程序。两种独立基线及完整搜索均使用标准库。
